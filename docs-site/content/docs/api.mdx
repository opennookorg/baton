title: API reference
description: Five HTTP endpoints for routing, learning and reading the graph.
---

Base URL of the live server: `https://baton-134858271117.us-central1.run.app`. On your own machine it is `http://localhost:8000`.

| Endpoint | What it does |
|---|---|
| `POST /route` | Route an issue to a team. |
| `POST /learn` | Teach Baton who fixed an issue. Needs a token on public servers. |
| `GET /stats` | The five dashboard counters. |
| `GET /curve` | The learning curve data. |
| `GET /graph?entity=scheduler` | The graph around one entity. |
| `/mcp` | The same tools for AI agents, over MCP. See [Connect your AI agent](/docs/agents). |

## Route an issue

```sh
curl -X POST https://baton-134858271117.us-central1.run.app/route \
  -H 'Content-Type: application/json' \
  -d '{"title": "kube-apiserver drops watch events under load", "body": "Clients log: context deadline exceeded"}'
```

| Field | Required | Meaning |
|---|---|---|
| `title` | yes | The issue title (up to 500 characters). |
| `body` | no | The issue text. Logs, paths and errors help. |
| `reporter` | no | GitHub username of the person who filed it. |
| `as_of` | no | Route against the graph as it was at 0, 500, 1000 or 1700 issues. |

The answer has the top teams (each with `team`, `share` and `path`), a `confidence`, and how many entities were found and unknown.

## Teach it an outcome

```sh
curl -X POST http://localhost:8000/learn \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $BATON_LEARN_TOKEN" \
  -d '{"number": 12345, "title": "...", "body": "...", "created_at": "2026-01-01T00:00:00Z", "team": "sig/node"}'
```

Baton rewards the links that pointed to `team` and penalises the ones that did not. If the issue is already in the graph, nothing changes.

## Limits

To keep the free server free, each IP gets per minute: 30 routes, 10 learns, 60 reads of `/graph`, `/curve` and `/stats`, and 120 MCP calls. Bodies over 64 KB are refused. Over the limit you get a `429` with a `Retry-After` header.
