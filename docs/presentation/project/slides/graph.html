Baton

The data model. Entities like scheduler point into the past issues they were seen in, and those issues point to the team that fixed them. That is a two-hop path. Learning adds direct ROUTES_TO links from an entity to a team, with a cost of one over strength, and SAME_AS links between names that always agree. All links point toward teams, so one outgoing path search from the issue's entities finds every route. The numbers on the right are the live graph after 1,700 learned issues; the issue count is higher because gap filling pulled in older reserve issues.
