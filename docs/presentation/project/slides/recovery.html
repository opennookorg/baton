Ownership changes, so we simulated a reorg. From learning issue 900, every sig/scheduling issue is fixed by sig/apps instead, and we score the 51 test issues that move. This is a simulation, on the in-memory mirror, not HydraDB, and the real labels never changed. Every line collapses at the reorg. Baton's penalties push the old links down, and by issue 1,400, 500 issues later, it is back above where it was, at 73 percent. Naive Bayes with no graph is still at 39 percent then; it catches up by 1,700 once the new counts outweigh the old. Nobody had to update a list.
