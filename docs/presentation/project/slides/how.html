How it works

Route, learn, repeat

1 · EXTRACT

Pull out entities

Components, file paths, words, error phrases and the reporter. Plain code, no AI model.

2 · ROUTE

One graph query

A weighted algo.MSpaths call from the issue’s entities to every team. A team scores 1 / cost per path.

3 · LEARN

Fix the links

When the fix lands, links that pointed right get cheaper, wrong ones dearer. Strong patterns become shortcuts.

4 · EXPLAIN

Show the path

The cheapest path is the reason: scheduler → past issues → sig/scheduling.

Every closed issue goes back in, so the graph that routes issue 2,000 is not the graph that routed issue 200.

Baton

Four steps. Extract entities with plain code. Route with one weighted path query from those entities to every team in HydraDB. When the real fix lands, reweight the links: the ones that predicted the right team get cheaper, the ones that pointed the wrong way get dearer, and strong patterns become direct shortcut links. The cheapest path is shown as the reason, so a triager can check it.
